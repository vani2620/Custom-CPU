This was meant to be a SystemVerilog project for a high-performance RISC CPU design. The specs were as follows:
- 32 bit instruction word
- 32 registers
- Load-store architecture
- Out-of-order issue and execution

Long story short, the project is currently on hold while I work on a series of smaller, less complex designs in order to polish my skills.

Huge shoutout to LordDeCapo and the LTDS server for helping me throughout the course of my journey of learning SystemVerilog. I would highly recommend all who encounter this project to check out his [ProcessORC CPU](https://github.com/LTDS-Capo/ProcessORC), as well as Slicudis' [SRM](https://github.com/SLicudis/SRM) and martandrMC's [PHINIX+](https://github.com/phinixplus).
